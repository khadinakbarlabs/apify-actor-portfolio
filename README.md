# Khadin Akbar Apify Actor Portfolio

This repository is a directory of Khadin Akbar's Apify Actors. It contains
portfolio metadata and direct links only.

## What you will find

- An Actor page for each catalogued tool
- An MCP entry point for using an available Actor through Apify MCP
- The Actor title and stable slug needed to find the right tool

The complete machine-readable directory is [actors.json](actors.json).

## Use an Actor

1. Open the Actor page in the catalog entry to review the current product
   description, inputs, pricing, and availability.
2. Use the MCP entry point when the Actor is available to your Apify account.
3. Keep your Apify credentials in your own Apify or MCP client configuration;
   never place them in this repository or a URL.

## Scope and privacy

This is a portfolio, not an Actor source repository. It contains no Actor
source code, build files, deployment settings, credentials, customer data,
session cookies, run outputs, or private Console links.

Availability, pricing, and MCP access are controlled by Apify and can change.
Always confirm the current Actor page before running a tool.

## Maintainer notes

Catalog entries are added from the live account inventory using only the Actor
slug, title, Actor URL, and MCP entry point. See
[catalog-policy.md](docs/catalog-policy.md) for inclusion rules.
